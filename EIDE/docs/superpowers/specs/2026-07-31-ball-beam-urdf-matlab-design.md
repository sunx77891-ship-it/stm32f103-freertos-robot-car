# 电赛 H 题球杆系统：SolidWorks → URDF → MATLAB 仿真 设计文档

日期：2026-07-31

## 1. 背景与目标

为 2026 年电赛 H 题（平衡钢球）搭建完整仿真链路：

1. **SolidWorks 建模**：按题目参数绘制固定式摆杆模型（无车身）
2. **URDF 导出**：通过 sw_urdf_exporter 插件导出 URDF + STL
3. **MATLAB 仿真**：URDF 解析 → 3D 动画 + 球杆解析动力学 + 串级 PID 闭环仿真

**用户环境（已确认）：**
- SolidWorks 2022
- MATLAB R2022a：Simulink 10.5、Simscape 5.3（基础版）
- **无** Robotics System Toolbox（无 importrobot）
- **无** Simscape Multibody（无 smimport，不能做 3D 物理引擎仿真）

**结论**：MATLAB 无法原生读取/物理仿真 URDF，采用方案 A —— URDF 作为单一事实来源（几何/关节/限位/惯量），MATLAB 自写解析器读取，动力学用经典球杆解析模型在 Simulink 中仿真。

## 2. 题目参数（H 题）

- 摆杆：25cm 长 4 分 PPR 水管改造（外径 2cm、壁厚 0.34cm → 内径约 1.32cm）
- 凹槽剖面：外圆弧半径约 1cm、内圆弧半径约 0.65cm
- 钢球：直径约 1cm，在凹槽内自由滚动
- 凹槽内壁光滑，不允许增摩擦改造
- 刻度线：贴在凹槽剖面边沿（不允许贴槽内），间距 0.1cm
- 钢球位置检测：必须用摄像头
- 摆杆整体平直

## 3. 机械结构设计（SolidWorks）

固定式摆杆系统，7 个零件，无车身：

```
        ┌──────── camera（摄像头，俯视槽口）────────┐
        │                                          │
   base（固定底座/支架，固定在桌面）                 │
   │     ┌────────────────────────────────┐        │
   │合页  │  beam（PPR 半圆槽摆杆 250mm）  │← 球在槽内滚动
   │ 左端铰接 │ 外径20 / 内槽R6.5 / 壁厚3.5  │        │
   └─────┴────────────────────────────────┘        │
                 ▲ 连杆(100mm) ▼ 舵机摇臂(R25mm)    │
                 │         驱动点：距左端120mm       │
                 └───────── MG996R 舵机 ─────────┘  │
```

**驱动方案**：摆杆左端合页铰接，右半段下方 120mm 处由连杆 + 舵机摇臂驱动。

| 零件 | 关键尺寸 | 材质/密度 |
|------|---------|-----------|
| `beam` 摆杆 | φ20×250mm，半圆凹槽内半径 6.5mm，槽底壁厚 3.5mm，中部下方 120mm 处驱动耳座（φ4 孔） | PPR 0.91 g/cm³，约 21g，绕左端惯量 4.3e-4 kg·m² |
| `ball` 钢球 | φ10mm，4.1g，I = 2/5·m·r² = 4.1e-8 kg·m² | 钢 7.85 g/cm³ |
| `hinge` 合页 | 两片 30×15×2mm 铝片 + φ3×25mm 轴，轴心与摆杆轴线共线 | 铝 |
| `base` 固定底座 | 底板 200×100×10mm；左端立板高 140mm（装合页）；右段舵机座平台高 55mm；合页轴心距底板 130mm | ABS |
| `servo` 舵机 | MG996R：40.8×19.7×42.9mm，扭矩 0.92 N·m，0.17s/60°，摇臂 R=25mm，工作角 ±60° | — |
| `link_rod` 连杆 | 总长 110mm，孔中心距 100mm，φ5 铝杆，两端 φ4 孔 + 4mm 球头 | 铝 |
| `camera` 摄像头 | 简化块 40×30×20mm，立柱悬于摆杆上方 30mm，垂直俯视槽口 | — |

**摆杆建模方法（关键）：**
- φ20mm 圆柱（长 250mm）→ 顶部画 φ13mm 半圆草图 → 拉伸切除 6.5mm（到轴线）→ 形成半圆凹槽
- 校验：内圆弧 R6.5mm、外圆弧 R10mm、槽底壁厚 10−6.5=3.5mm（≈ 题目 3.4mm）

**机构行程核算：**
- 驱动点距左端 120mm，舵机 ±60° → 摇臂端点行程 ±25·sin60° ≈ ±21.6mm → 摆杆倾角 ±10.2°
- 球加速度能力 a = (5/7)·g·sin10.2° ≈ 1.24 m/s²（0→0.5m/s 需 0.4s，够电赛动态）
- **倾角限位 ±0.2 rad（±11.5°）**，与机构行程匹配

**装配约束：**
- 合页轴与摆杆轴线共线（旋转副），合页固定片装底座立板顶面
- 舵机固定于底座右段平台，摇臂端点孔 ↔ 连杆 ↔ 摆杆驱动耳座孔（φ4 销）
- 摆杆水平时连杆近似竖直
- 钢球与凹槽同心配合（球半径 5mm < 槽半径 6.5mm，可滚动）

**旋转支点**：左端合页（教科书经典 ball-on-beam 构型，球位置零点在铰接端，控制模型标准）。

## 4. URDF 结构

坐标系树（自由度与真实结构一致）：

```
base_link(固定底座) ──joint_beam(revolute, y轴)── link_beam(摆杆)
                                                    └─joint_ball(prismatic, 沿杆x轴)── link_ball(钢球)
base_link ──joint_camera(fixed)── link_camera(摄像头)
```

- 杆倾角限位：θ ∈ [-0.2, +0.2] rad（±11.5°，与驱动机构行程匹配）
- 球行程：x ∈ [0.01, 0.24] m（零点在左端合页轴）
- 惯量：SolidWorks 材质设置后由插件自动计算；导出后人工校验钢球（4.1g，I = 2/5·m·r² = 4.1e-8 kg·m²）

**导出工具**：sw_urdf_exporter（SW2022 兼容），输出 URDF + STL mesh 到 `model/` 目录。

## 5. MATLAB 仿真实现

代码位置：`D:/MATLAB/ball_beam/`

```
ball_beam/
├── model/                    # SW 导出的 URDF + STL（单一事实来源）
├── parse_urdf.m              # xmlread 解析 URDF → 结构体（几何/关节/限位/惯量）
├── visualize_ball_beam.m     # patch 重建 3D 场景：摆杆绕轴旋转 + 球沿槽滚动
├── ball_beam_dyn.m           # 状态方程（供 Simulink S-Function 或脚本仿真）
├── ball_beam_ctrl.slx        # 串级 PID 闭环仿真
├── tune_ball_beam.m          # 平衡点线性化 + pidtune 初值 + 仿真微调
└── run_sim.m                 # 一键仿真 + 后处理 3D 动画播放
```

**动力学模型（解析，球杆经典）：**
- 状态：x = [x_ball, xdot_ball, θ, θdot]
- 球滚动（纯滚动实心球，I = 2/5·m·r²）：x'' = (5/7)·(g·sinθ − μ·x')
- 杆：MG996R 舵机位置闭环，一阶伺服模型（时间常数约 0.06 s，角速度限幅 6 rad/s）+ 角度饱和 ±0.2 rad
- 参数（密度 → 质量/惯量）从 URDF 读取，保持模型一致性

**控制方案（串级 PID）：**
- 内环：舵机位置闭环（伺服模型），θ 快速跟踪 θ_ref
- 外环：球位置 PID：θ_ref = Kp·e + Ki·∫e + Kd·ė，e = x_target − x_ball
- θ_ref 限幅限速，防舵机饱和
- 调参：平衡点（θ=0）线性化得双积分对象 x'' = (5/7)·g·θ → pidtune 给初值 → 仿真微调

**3D 动画（后处理）**：
- `run_sim` 仿真 → 数据落 Workspace → 播放动画（patch 更新：摆杆绕铰接轴旋转、球沿槽滚动）
- 用 MATLAB 基础函数（cylinder/sphere/patch）重建几何，不依赖 STL 读取工具箱

## 6. 验证标准

1. 定点稳定：球从 0.2m 回到目标 0.1m，超调 <10%，无静态误差
2. 轨迹跟踪：目标正弦/梯形轨迹，跟踪误差在 ±1cm 内
3. 动画：摆杆旋转、球滚动与状态一致
